Research & interests

I’m interested in how the way we write requirements and organise software projects shapes the software we build.

Research project

Requirements and AI-generated code

In a study with a colleague, we asked whether changing what goes into a software requirements specification affects the quality of the code an AI model generates.

We created six versions of the specification for the same to-do list application and generated five applications from each version. We evaluated the 30 applications using 39 JUnit tests and static analysis with SonarQube.

What I’m curious about

Studying behavioural software engineering and project management made me curious about how teams set priorities, make trade-offs, and organise their work. I’m especially interested in what happens when a decision that makes sense for one team creates extra work for another.
